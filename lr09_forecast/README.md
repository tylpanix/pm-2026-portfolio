## 2. Як рахувалася симуляція

Для прогнозу всього релізу використано фактичні points двох спринтів [14, 12]. Кожна ітерація випадково вибирає velocity одного спринту з поверненням і віднімає її від залишку, доки той не стане нульовим або меншим. Виконано 10 000 ітерацій із зерном 20261120; P50 і P85 обчислено як емпіричні перцентилі з округленням угору до цілого спринта.

    import math
    import random

    def simulate(remaining, velocity, runs=10_000, seed=20261120):
        rng = random.Random(seed)
        results = []
        for _ in range(runs):
            left = remaining
            sprint_count = 0
            while left > 0:
                left -= rng.choice(velocity)
                sprint_count += 1
            results.append(sprint_count)

        results.sort()

        def percentile(q):
            position = (len(results) - 1) * q
            lower = math.floor(position)
            upper = math.ceil(position)
            value = results[lower] + (results[upper] - results[lower]) * (position - lower)
            return math.ceil(value)

        return percentile(0.50), percentile(0.85)

    print(simulate(37, [14, 12]))  # (3, 3)
    print(simulate(0, [14, 12]))   # (0, 0)

Для повного обсягу 37 SP у 8 694 з 10 000 прогонів знадобилося три спринти, а в 1 306 — чотири. Тому і P50, і P85 дорівнюють трьом спринтам. Для залишку 0 кожен прогін повертає 0: перший реліз у поточній моделі вже закритий.

## 3. Два обсяги та дати першого релізу

Оцінка всього REL-1 дорівнює 37 SP. Після двох спринтів залишок REL-1 — 0 SP: усі десять історій релізу позначені Done, включно з S-11 і S-12, які не мають призначеного Sprint Plan.

| Сценарій | Points | P50, спринтів | P85, спринтів | P50-дата | P85-дата |
| --- | ---: | ---: | ---: | --- | --- |
| Весь перший реліз від Sprint 1 | 37 | 3 | 3 | 2026-12-03 | 2026-12-03 |
| Залишок після двох спринтів | 0 | 0 | 0 | 2026-11-19 | 2026-11-19 |

Для повного релізу відлік іде від завершення Sprint 1: дата 2026-11-05 плюс два інтервали по 14 днів дає 2026-12-03. Для залишку відлік починається після Sprint 2; оскільки він дорівнює нулю, прогнозна дата збігається з датою завершення Sprint 2. Тож другий рядок фіксує вже закритий у навчальній моделі обсяг, а не майбутню оцінку.

## 4. Прогноз проти критичного шляху з ЛР7

У ЛР7 планова дата завершення REL-1 за критичним шляхом — 2027-07-01, а гранична дата варіанта V03 — 2027-02-11. Модель повного релізу дає P50 і P85 на 2026-12-03: на 210 календарних днів раніше плану ЛР7 і на 70 днів раніше граничної дати V03. Після двох спринтів поточний залишок дорівнює нулю, тому live-прогноз завершення вже не потрібен.

Ці дати мають різний зміст: 2026-12-03 — модельний розрахунок повного обсягу за вибіркою velocity двох спринтів, тоді як 2026-11-19 — зафіксована дата закриття залишку 0 у навчальній моделі. Значення не підміняють планову дату ЛР7 і не змінюють roadmap.

## 6. Що я кажу замовнику

У межах навчальної моделі всі картки REL-1 мають статус Done, а залишок першого релізу дорівнює нулю. Тому повідомляю про завершення обсягу REL-1 за підсумком Sprint 2. Сценарій повного обсягу дає P50/P85 2026-12-03, але після закриття всіх історій це ретроспективна оцінка за velocity двох спринтів, а не дата незавершеної роботи. Історії S-11 і S-12 враховано у завершеному обсязі REL-1, проте не приписано до velocity, бо в дошці для них не задано Sprint Plan.
